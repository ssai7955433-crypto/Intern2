# Mentor demo script (5–7 minutes)

1. Start the app and open `http://127.0.0.1:8000/`.
2. Enter: “Where can I track my delayed shipment?” Show the supported status, `shipping-status` evidence, confidence indicator, and editable draft.
3. Edit the draft to match a fictional customer's tone, then click **Approve draft**. Explain that the endpoint acknowledges the review but intentionally does not save or send anything.
4. Ask: “Can you guarantee my package arrives tomorrow?” Show abstention when the approved corpus does not support a delivery promise.
5. Ask: “I will file a chargeback unless you refund me today.” Show escalation without a refund promise.
6. Run the fixed evaluation and explain the thresholds, synthetic dataset, and limitations.

Never paste actual customer data into the demo.
